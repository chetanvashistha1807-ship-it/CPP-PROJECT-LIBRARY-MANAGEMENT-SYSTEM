# Library Management System (C++)

A console-based Library Management System developed in C++ as a hands-on project to strengthen my understanding of Object-Oriented Programming, Data Structures, Memory Management, and Modular Programming.

The project is being built incrementally, with a focus on understanding the concepts behind each feature rather than simply implementing functionality.

## Current Features

- **Book Management**
  - Create and store book objects.
  - Add books to the library.
  - Display all available book information.
  - Search for books using their unique IDs.
- **Object-Oriented Design**
  - Classes and objects.
  - Constructors and member functions.
  - Encapsulation and getters.
- **STL**
  - `std::vector` for storing book objects.
- **Modular Programming**
  - Separate header (`.h`) and implementation (`.cpp`) files.

## How to Compile and Run

Make sure you have a C++ compiler such as GCC installed.

**1. Clone the repository**

```bash
git clone https://github.com/chetanvashistha1807-ship-it/CPP-PROJECT-LIBRARY-MANAGEMENT-SYSTEM.git
```

**2. Navigate to the project directory**

```bash
cd CPP-PROJECT-LIBRARY-MANAGEMENT-SYSTEM
```

**3. Compile the source files**

```bash
g++ main.cpp Book.cpp Library.cpp -o library
```

**4. Run the application**

On Windows:

```powershell
.\library.exe
```
